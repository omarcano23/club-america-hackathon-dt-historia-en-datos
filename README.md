Club América: DT, historia en datos

Informe interactivo de análisis táctico del Club América.
👉 [Ver informe interactivo](report/index.html)

Este proyecto analiza la identidad de juego del Club América de André Jardine durante las temporadas 2023-24 y 2024-25 a partir de datos de eventos y StatsBomb 360. 

La narrativa se organiza en seis capítulos: 
1. Identidad
2. Progresión
3. Recuperación
4. Partido a partido
5. Balón parado
6. Legado

Los resultados describen patrones observados, comparan grupos y documentan la incertidumbre estadística y las discrepancias entre marcadores de referencia y goles reconstruidos desde eventos. La experiencia web busca traducir las métricas en una historia comprensible para público no especializado, explicando también las definiciones, los supuestos y las limitaciones del análisis.
